# FARS v0.7 · Набор графики для кабинета

**Файлы в эту папку загружаются отдельно** из архива `fars-v07-templates.zip` (в чате ChatGPT). GitHub Pull Request содержит интеграцию в HTML/CSS/JS, но бинарные PNG через доступное подключение GitHub автоматически отправить не получилось.

Точные имена файлов (загружайте в эту папку, без дополнительной вложенной папки):
- `panel-main.png` — большой пергаментный шаблон панели текущего испытания;
- `auction-blank.png` — оформленная пустая аукционная панель, все игровые данные динамические;
- `dice-luck.png` — отдельный нарисованный кубик с золотыми звёздами;
- `profile-crest.png` — орнамент для аватара в личном кабинете;
- `auction-art.png` — исходная полная декоративная иллюстрация для будущих страниц, сейчас не используется, потому что на ней запечены ненастоящие данные;
- `action-banner.png` — большой декоративный баннер «Продолжить», для будущих сценариев; сейчас не заменяет живые кнопки.

## Загрузка
1. Открыть ветку `feature/v0.7-art-templates` и папку `assets/ui-v07`.
2. `Add file → Upload files` и перетащить **6 PNG** из архива.
3. `Commit changes` в ту же ветку.
4. В PR убедиться, что GitHub Actions прошёл. После этого объединить PR с `main`.

Никакие правила Firebase или изменения в сохранённых сезонах для этого обновления не нужны. Текст кнопок, названия игр, состояния аукциона и результат броска не находятся внутри PNG и берутся из интерфейса/состояния сезона.
