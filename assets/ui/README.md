# FARS v0.5 — UI-kit assets

Ветка `feature/v0.5-art-ui-kit` содержит новый CSS-макет. Реальные PNG не загружаются автоматически через подключение GitHub: они поставляются отдельным архивом `fars-ui-v05-assets.zip`.

## Загрузка PNG через GitHub

1. Распакуйте ZIP.
2. На GitHub выберите ветку **feature/v0.5-art-ui-kit**.
3. Откройте каталог **assets/ui**. В нём лежит этот файл README.
4. Нажмите **Add file → Upload files** и перетащите **содержимое** папки `assets/ui` из архива (16 PNG, не всю родительскую папку).
5. Нажмите **Commit changes** с сохранением в текущую ветку.
6. Убедитесь, что путь каждого файла выглядит `assets/ui/logo.png`, `assets/ui/panel-dark.png` и т.д.
7. Вернитесь в Pull Request и после проверки объедините с `main`.

Слова и данные НЕ запечены в декоративные кнопки и панели. Использовать их нужно как CSS border-image/background, а поверх выводить HTML-текст.

На сайте карта по-прежнему использует фиксированные `assets/fars-board-v04.svg` и `board-map.mjs` — калибровка фишки не меняется.

Если не загрузить PNG, появится более простой запасной вариант из CSS; сайт останется работоспособным. После загрузки для проверки обновите страницу через Ctrl+F5.
